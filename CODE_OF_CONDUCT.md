# Code of conduct

We follow the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Be respectful, constructive, and specific. Harassment, discrimination, doxxing, and publishing another person's private session data are not acceptable. Project maintainers may remove content or participation that violates these expectations.

Report conduct concerns privately through the repository's security/contact path when a public issue would expose a person or private data.
